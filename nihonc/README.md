# nihonc

Compiler for the **Nihon** programming language (`.nihon`). Status: stage 0, slice 1 (lexer + diagnostics).

Zero external dependencies.

```bash
cargo build --release
cargo test                      # unit tests + diagnostic output tests
target/release/nihonc file.nihon
target/release/nihonc --tokens file.nihon
target/release/nihonc --romaji file.nihon   # accepts kansuu, moshi... without warnings
target/release/nihonc --strict file.nihon  # every warning becomes an error
```

Example (`//` = romaji reading and meaning):

```rust
関数 主() {                      // kansuu shu() = main function
    表示!("こんにちは世界");     // hyouji!("konnichiwa sekai") = prints "hello world"
}
```

## Project structure

- `src/source.rs` — source text, byte spans, column width calculations (kanji = 2)
- `src/width_table.rs` — generated by `tools/gen_width.py` (do not edit manually)
- `src/diag/` — diagnostics, error code catalog, diagnostic rendering
- `src/lexer/` — lexer, character classes, keyword table (Japanese + romaji)
- `tests/ui/` — one `.nihon` + expected `.stderr` per test case (`BLESS=1 cargo test --test ui` to update expected output)
